# Paul Monaghan

I've spent 25+ years in technology, most of it leading engineering teams. These
days I run [Viewbridge AI](https://viewbridge.ai), a small AI consulting and
product company in Ontario.

Most of what's here started as something I wanted for myself.

**[hive](https://github.com/paulmona/hive)** is the big one. Four Claude Code
agents run side by side on one VM, each with its own job. One handles my
calendar and morning briefing, one writes code with me, one looks after
Viewbridge email, and one does research. I can reach them by voice, from the car
or from my phone, and they remember the conversation across all of them. The
repo is the actual config they run on, cleaned up for public.

**[ha-claude-integration](https://github.com/paulmona/ha-claude-integration)**
is the piece that lets Home Assistant voice talk to those agents.

**[GarminConnectMCP](https://github.com/paulmona/GarminConnectMCP)** gives
Claude access to my Garmin data, so it can plan training around how I actually
slept.

**PromptLineAI** ([backend](https://github.com/paulmona/PromptLineAI-BackendAPI),
[extension](https://github.com/paulmona/PromptLineAI-extension)) is a proof of
concept from earlier this year: a way for a company to see how its people use AI
tools without recording what they type.

**[pm](https://github.com/paulmona/pm)** is a Claude Code plugin I use to take
an idea through to a PRD, a TRD and a GitHub project.

**[little-library](https://github.com/paulmona/little-library)** catalogues the
little free library at the end of my driveway.

## What I'm playing with now

I'm experimenting with [Paperclip](https://github.com/paperclipai/paperclip) for
running agents as a team rather than one at a time. So far that's a chief of
staff agent, a small marketing team, and inside sales agents that research each
lead before anyone reaches out (for example, checking MX records to see what the
company uses for email) and write what they find back to HubSpot.
